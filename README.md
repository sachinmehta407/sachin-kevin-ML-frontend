# Forecast Control Room — Frontend Demo

Complete static React prototype for **Intelligent AutoML Sales Forecasting & Decision Platform**.

No backend. Mock data + Zustand (persisted) + Recharts.

## Run

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173/

## Journey

Overview → Ingestion (Load Demo) → Data Quality → Standardization → EDA → Model Selection → Training → Dashboard → Experiments → Ensemble → Overrides → Template Compare → Approval → Versions

Use **Ask the Forecast** for static Q&A. **Reset demo** clears localStorage state.

## Stack

React 18 · TypeScript · Vite · Tailwind · Recharts · React Router · Zustand · Lucide
